# Assets: `assets`

This directory contains static resources, primarily images and diagrams, used in the `README.md` and other documentation. 

These files visualize the project architecture, agent interactions, and CLI outputs. 

## Contents
*   Architectural schemas (`schema.png`)
*   Agent role illustrations (`analyst.png`, `researcher.png`, `trader.png`, `risk.png`)
*   CLI demo screenshots (located in `assets/cli/`)
*   Logos and branding images

No code or application logic resides in this folder. If you are updating the README architecture diagrams, place the updated images here.
