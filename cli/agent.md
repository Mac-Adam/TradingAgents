# Command Line Interface: `cli`

This directory houses the logic for the interactive CLI application used to run the TradingAgents framework from the terminal.

## Key Files & Modules

*   **`main.py`**: The primary entry point for the CLI. It uses a terminal UI library (likely `rich` or similar) to present an interactive menu, allowing the user to select tickers, dates, LLM providers, and configuration options. It then instantiates `TradingAgentsGraph` and streams results.
*   **`config.py`**: CLI-specific configuration handling (e.g., parsing arguments, reading environment variables).
*   **`models.py`**: Contains data structures or enums relevant strictly to the CLI parameters.
*   **`stats_handler.py`**: Handles processing and formatting statistics/results generated by the framework for display in the terminal.
*   **`utils.py`**: Helper functions for CLI formatting, spinner animations, file reading, and console output.
*   **`announcements.py`**: Logic to print version updates, news, or warnings when the CLI starts.

## Design Patterns

*   The CLI acts strictly as a presentation layer. It does not contain core trading logic or data fetching. It configures the `TradingAgentsGraph` and subscribes to its output stream, formatting the output nicely for the user.
*   If you need to add a new command-line flag or interactive prompt option, start in `main.py` and trace how the configuration object is built before being passed to `TradingAgentsGraph`.
